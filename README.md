📌 Project Overview

This project demonstrates an interactive Decision Tree Visualization built using the GoJS library. The application represents hierarchical decision-making logic in a structured and visually clear format.

The goal of this project is to understand how decision trees work conceptually and how they can be displayed dynamically in a web interface.

Features

Interactive hierarchical tree structure

Clear branching representation

Structured decision flow visualization

Clean and organized UI layout

🎯 Learning Outcomes

Through this project, I gained a better understanding of:

Decision tree logic and structure

Data visualization techniques

Hierarchical modeling in web applications

Implementing external JavaScript libraries

🔮 Future Improvements

Add dynamic user input for tree generation

Connect with real dataset for classification
